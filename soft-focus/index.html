01 / เลือกทิศทาง

Sunny ใช้พื้นอุ่น ปุ่มเหลือง และการ์ดชมพู–ม่วงอ่อน เหมาะกับเช็กอิน บันทึก และการเรียนรู้

Lavender ใช้พื้นชมพูอมม่วง การ์ดขาว และสีแยกหมวด เหมาะกับติดตามกิจกรรมหรือจัดข้อมูลส่วนตัว

02 / เชื่อมกับโปรเจกต์

  1. โหลด tokens.css ก่อน components.css
  2. ตั้ง data-theme="sunny" หรือ data-theme="lavender" ที่ root
  3. ใช้คลาส sf-card, sf-button, sf-field, sf-nav
  4. อ่านตัวอย่าง React ใน react.jsx และคู่มือใน README.md

03 / ปรับให้เป็นผลิตภัณฑ์จริง

  • กำหนดงานหลักของแต่ละหน้าก่อนเลือกคอมโพเนนต์
  • มือถือใช้หนึ่งคอลัมน์ ข้อมูลสรุปสั้น ๆ ใช้สองถึงสามคอลัมน์ได้
  • เมนูด้านล่างไม่เกิน 5 รายการ และเว้น safe area
  • แสดง loading, empty, error และ success ใกล้จุดที่เกิดเหตุ
  • เดโมนี้เก็บข้อมูลเฉพาะในหน่วยความจำ รีเฟรชแล้วเริ่มใหม่

ที่มาของแนวทาง

ตีความสีและรูปทรงจากภาพอ้างอิงสองภาพที่คุณส่งมา ค่าสีเป็นค่าประมาณ ไม่ใช่ไฟล์ต้นฉบับ ภาพประกอบและโค้ดในชุดนี้สร้างใหม่ ไม่มีการนำแบรนด์หรือเนื้อหาของแอปอ้างอิงมาใช้
